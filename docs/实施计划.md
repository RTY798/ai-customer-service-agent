# 电商智能客服系统 — 改造实施计划

## 改造目标

1. **更名**："AI 智能客服 Agent 系统" → "电商智能客服系统"
2. **新增 CLI**：支持终端命令行对话
3. **数据源抽象**：当前模拟数据做成可替换的 Provider 模式，其他人下载后只需实现接口即可接入真实数据
4. **开源就绪**：CONTRIBUTING.md + DATA_PROVIDER.md + 清理配置

### Step 2: 数据抽象层（核心改造）

新建 `backend/app/data/` 包：

```
backend/app/data/
├── __init__.py
├── base.py          # 数据模型 (dataclass) + 抽象接口 (ABC)
├── demo_provider.py # 当前模拟数据包装为 Provider
└── config.py        # Provider 选择逻辑 (env → import)
```

**base.py** — 定义 `Order`, `Shipment`, `Product`, `ReturnPolicy`, `KnowledgeDoc` 数据类，以及 `ECommerceDataProvider` 抽象基类

**demo_provider.py** — 从 `tool_agent.py` 和 `knowledge_base.json` 迁移现有模拟数据，实现 `ECommerceDataProvider`

**config.py** — `get_data_provider()` 根据 `settings.data_provider` 动态导入 Provider

**改动的现有文件**：
- `backend/app/config.py` — 新增 `data_provider: str = "demo"`
- `backend/app/agents/tool_agent.py` — 删除 4 个硬编码字典，改为调用 `get_data_provider()`
- `backend/app/knowledge_base/vector_store.py` — `_load_docs()` 改为通过 Provider 获取文档

### Step 3: CLI 交互模式

新建 `backend/app/cli.py`，支持：
- `python -m app.cli` 启动交互式终端对话
- 输入问题 → 调用 agent_graph → 显示回复
- 显示思维链摘要（紧凑格式）
- 显示工单信息
- 命令 `/quit` `/help`
